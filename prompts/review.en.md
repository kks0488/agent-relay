# Review rules

- Report only actual errors supported by the source: incorrect facts, numbers, dates, broken behavior, missing requirements, or exposed secrets.
- Give a file and line number (or a precise source paragraph), what is wrong, evidence, and the smallest correction for each finding.
- No nitpicks, style preferences, naming preferences, speculative risks, or unrelated improvements.
- Distinguish confirmed errors from uncertainty. Do not invent findings.
- Read only. Do not change files or take external actions.
- If there are no confirmed errors, write "Findings: 0".
- End with "Findings: N", using the actual count.
